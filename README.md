# Brutalist Portfolio — GDG Gallery Example

A fictional student portfolio created for GDG on Campus York University's *Build & Ship Your Portfolio* workshop.

This example demonstrates how the `vibe-brutalist` design skill transforms a student portfolio into a bold, high-contrast website with oversized typography and geometric layouts.

## What it is

This portfolio features Sam Rivera, a fictional first-year Computer Science student at York University.

The website includes Home, About, Projects, Skills, and Contact sections, showcasing two fictional projects:

- **Bus Buddy:** A Python script showing upcoming campus bus departures.
- **Study Timer:** A Pomodoro timer website built with HTML, CSS, and JavaScript.

All student information and projects are fictional and intended for workshop demonstration.

## Live site

[View the Brutalist portfolio](https://gdgyork-brutalist.web.app)

## How it was built

- **Planning:** Used `SPEC.md` to define the fictional student's background, portfolio sections, projects, and skills.
- **Website:** Built a responsive website using HTML and CSS in the `public/` directory.
- **Design:** Followed Sahand's finalized `vibe-brutalist` skill, using a cream background, oversized Archivo Black typography, Space Mono body text, thick black borders, sharp corners, asymmetric project tiles, and restrained red accents.
- **AI tools:** Used ChatGPT to help implement the HTML and CSS based on `SPEC.md` and the official design skill.
- **Testing:** Reviewed the website on desktop, 365px mobile, and 768px tablet layouts. Tested navigation and contact links.
- **Version control:** Used Git and GitHub to track and publish the source code.
- **Hosting:** Deployed the website using Firebase Hosting.
